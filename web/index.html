变更日志 (Changelog)

v1.0.0 2026-11-21 首个正式发布版本
  • 支持通过 esptool 自动检测 ESP32 芯片型号、MAC 与 Flash 容量，一键读取并备份原始程序（含版本号与 SHA-256 校验）。
  • 支持下载备份 .bin 文件、一键恢复原厂固件及上传自定义 .bin 烧录。
  • 内置实时串口监视器（本地服务 SSE 流 + 浏览器 Web Serial API 双模式）。
  • 新增「需求工坊」：输入 ESP32 新功能需求自动生成 Arduino / ESP-IDF / MicroPython 代码框架，并支持同步至 GitHub Issue。
  • 新增「ESP32 应用广场」：聚合 12 款当前 GitHub 最新热门 ESP32 开源应用并支持实时搜索。
